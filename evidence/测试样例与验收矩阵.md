# 测试样例与验收矩阵

| 类别 | 输入/触发 | 预期 | 实际证据 | 判定 |
| --- | --- | --- | --- | --- |
| 正常 | 15 个合成输入完整；审计 DEMO_A_c1 / DEMO_B_c1 | inventory→PMF×2→MD×2→SAPT；工具字段与样本数正确 | real_agnes/revised-verified.json、display-session-export.jsonl | 完整核验通过 |
| 边界 | 两个 MD CI 均跨零；PMF 标准态修正=false | 方向未分辨；保留范围限制 | boundary-case.json、同一真实正常会话的工具返回 | 通过；不等于证明两组相同 |
| 失败 | 临时移除 AI/audit.json | 14/15、EVIDENCE_FILE_MISSING、不生成缺失 SAPT 数值 | real_agnes/failure-result.json、failure-answer.md、错误截图 | 错误反馈通过；初始标签有错误 |
| 恢复 | 恢复源文件并重新安装、新建会话 | 15/15、SAPT interpolation_diagnostic_only | real_agnes/recovery-result.json | 工程恢复通过 |
| 输入边界 | 坏 JSON/CSV、不支持条件和指标、过小复本数、反向 CI | 对应结构化错误 | offline_validation/local-cases.json | 以此次实测断言结果为准 |
| 配置迁移 | 替换 MD 列名/比较名/指标 | 同一工具按配置读数 | offline_validation/local-cases.json 中 configuredCustomMd | 以此次实测断言结果为准 |
| Host 正常/失败 | 无外部模型的确定性 Provider | 安装信任启用运行，工具序列和失败返回 | offline_validation/host-fixture-*.json | 仅验证 Host 工程结构 |
| 报告展示 | 同会话请求直接展示已有报告 | 不重跑工具、完整报告显示、字段正确 | real_agnes/display-verification.json、最终展示报告.md | 实测通过 |

工具字段：tool_version=0.2.0，config_version=1.0；合成 SAPT 输入=8 样本、4 骨架、2 家族；分组原文 loso/lofo。PMF 井深 1.2/1.4 kcal/mol；MD 比较 DEMO_A-minus-DEMO_B，contact CI [-1, 0.6]，bridge CI [-0.5, 0.5]，每组 3 个模拟测试复本。以上全部为测试值，不是科研结果。

本作品没有本地设备调用；外部能力为 Agnes 模型 API 和 AGH Host 中注册的四个只读数据工具。证据包含模型路由、会话 ID、插件状态、调用参数、结构化输出、错误和恢复过程。
