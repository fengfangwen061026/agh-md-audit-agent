## 作品名称

基于 Agnes Harness 的通用型 MD 数据分析智能体

## 作品简介（41 字，含标点与英文字母）

基于AGH的分子模拟数据分析智能体，支持证据核验、定制审计、异常反馈和全程可追溯。

## 作品详情

本作品面向分子动力学（MD）及相关分子计算中的汇总数据分析，开发基于 Agnes Harness（AGH）的可扩展智能体原型。针对科研分析中数据分散、处理步骤重复、统计口径不一致和结论难以追溯等问题，系统将自然语言任务、数据检查、专用分析工具与证据化报告串联，帮助研究人员明确“数据是否完整、结果支持什么、结论有哪些限制”。

一、实现方案

系统采用“AGH运行底座＋配置驱动的数据检查＋专用工具与Skill”的结构。AGH负责插件装载、工具调用和会话留痕；Agnes模型负责理解任务、组织步骤及解释结果；只读工具负责读取汇总文件、执行明确判据并返回结构化结果。当前真实运行使用agnes-ai服务的agnes-3.0-flash模型，不包含本地模型权重，也不自行训练模型。

通过配置文件明确输入文件、必需字段、比较条件、指标名称、单位和独立复本要求；Skill规定调用顺序、异常处理与结论范围。在保持输入语义一致时，可通过配置适配新的条件或字段；不同分析方法则需要增加数据适配或专用工具。

二、核心功能

1. 证据盘点：检查JSON/CSV汇总文件是否齐全、格式及必需字段是否符合约定，明确缺失项与异常项。
2. PMF质量核验：读取指定条件的井深、置信区间、bootstrap与窗口重叠信息，保留标准态修正等范围限制。
3. MD复本比较：按独立复本读取条件差异和95%置信区间；区间跨零时明确提示方向未分辨，不将均值方向直接解释为材料优势。
4. SAPT分组审计：核对已有分组评估结果的样本数、骨架数、家族数和loso/lofo分组，限定为分组插值诊断。
5. 异常反馈与追溯：缺文件、坏格式、非法数值或不支持的指标返回明确错误；保存工具参数、返回值、错误及模型报告，便于逐项人工核查。

三、定制化路径与技术亮点

作品已提供《科研分析定制化改造指南》和项目需求配置模板，将新课题的接入分为四类路径，明确各类需求应修改哪些内容、提供哪些材料，以及如何验证交付结果：

1. A类——配置替换：分析语义和统计定义一致，仅项目名、条件名或字段名变化时，通过配置调整数据路径、条件列表、指标及字段映射。
2. B类——数据适配：分析问题相同，但文件结构、单位或分组方式变化时，增加字段映射、单位换算或本地预处理，将输入整理为工具可读取的汇总证据。
3. C类——方向工具包：新科研方向需要新的指标、质量判据或结论边界时，扩展专用工具，并配套配置、Skill和测试样例。
4. D类——新计算方法：涉及新的反应坐标、量化方法或自由能计算时，先建立并验证独立方法模块，再接入AGH工具和工作流；该路径提供扩展指引，不代表当前已自动实现任意计算方法。

用户只需按模板说明研究问题、输入文件、指标定义、单位、独立复本和期望比较，无需自行判断应改配置还是重写工具。项目依据上述路径确定改造范围，形成对应的插件或配置包、Skill、运行说明和验证记录。定制流程按“研究问题→输入与统计定义→质量门槛→工具与Skill→正常、边界、失败测试→AGH运行证据”组织，便于将已有工作流迁移到新的科研任务。当前已验证配置驱动的字段映射适配；新领域工具和新计算方法仍需逐项开发与验证。

用户输入审计任务后，系统加载对应Skill，依次完成证据盘点、PMF质量检查、MD复本比较和SAPT分组审计，再组织带来源、状态和不确定性的报告。遇到缺失证据时，允许检查其他有效文件，但不得依赖缺失结果形成判断；恢复文件后，通过重新装载和新会话验证恢复效果。

作品的技术特点是将任务组织与数值核验分工，实现可配置的输入约定、可扩展的只读工具和可追溯的执行记录。统计不确定性和质量限制作为结果的一部分直接呈现，工具原文与模型解释同时保留，便于发现和复核表述偏差。

四、运行验证与交付

已完成离线工具测试、AGH Host装载测试及真实Agnes正常与缺文件任务实测。验证覆盖正常、置信区间跨零边界、缺文件失败及恢复，并补充坏JSON/CSV、非法数值、不支持条件或指标、字段映射适配等样例。真实模型记录与本地确定性测试记录分别标注，提交材料包含会话标识、工具参数与输出、错误码、完整事件导出和界面截图。

可运行包提供插件、Skill、AGH本地运行时、合成测试输入、定制化改造指南、项目需求配置模板、启动脚本、环境说明、第三方声明和SHA256校验。离线工具层需要Node.js 24.10及以上；真实模式另需Agnes账号凭据与网络。本机验收环境为Node.js v24.18.0、macOS arm64。

本次提交使用团队构造的合成测试数据验证工程流程，不含私有科研数据或账号密钥。当前版本面向规范化汇总证据，不包含任意原始MD轨迹的通用解析和模拟重计算；合成测试结果不能作为科学机制、宏观相分离或材料普遍优势的证明。
