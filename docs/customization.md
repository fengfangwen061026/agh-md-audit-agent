# AGH 科研分析定制化改造指南

本项目当前的交付目标是：让新的科研课题能够快速接入**已整理的 MD/PMF/QM 汇总证据**，完成可追溯审计。原始 MD 轨迹的通用解析和指标计算暂不纳入本轮工期。

用户不需要从头设计插件。先根据下面的路径判断改造范围，再按对应模板准备文件。

## 先判断走哪条路径

| 路径 | 适用情况 | 需要改什么 | 典型工期 |
| --- | --- | --- | ---: |
| A 配置替换 | 文件语义、统计定义和指标含义都与现有工具一致，只是项目名、条件名或列名不同 | `audit_config.json`、数据目录、来源说明 | 0.5–1 天 |
| B 数据适配 | 统计问题相同，但 CSV/JSON 结构、字段名、单位或分组方式不同 | 配置、输入适配、少量工具代码、fixture | 1–3 天 |
| C 方向工具包 | 新课题需要新的指标、质量判据或结论边界 | 新工具、Skill、配置、测试和证据模板 | 3–7 天 |
| D 新计算方法 | PMF、QM、反应坐标、自由能分解等方法本身发生变化 | 独立计算模块、方法验证、工具和 Skill | 1–3 周以上 |

如果无法确定路径，先按“B 数据适配”估算；只有当科学判据确实改变时才升级到 C 或 D。

## 每条路径怎么做

### A：配置替换

适用于仍然使用当前四类工具语义的项目：证据清单、PMF QC、独立复本对照、分组模型审计。

1. 复制 `agh_scientific_audit/data/` 为新项目数据目录。
2. 修改 `audit_config.json` 中的 `dataset`、文件路径、条件列表、指标列表、字段映射和样本门槛。
3. 保留每个指标的真实单位，不要用配置改名掩盖单位或定义变化。
4. 更新 `run_manifest.json` 和 `provenance.json`。
5. 运行 `node tests/run_local_cases.mjs`，至少保留一次正常样例和一次跨零边界样例。

如果只是可由现有配置表达的字段映射变化，可以保持 `index.mjs` 不变。随包 Skill 和测试使用具体的演示条件与指标；条件名、比较名或指标名变化时，也应同步更新 Skill 与测试中的调用参数，避免保留旧项目名称。

### B：数据适配

适用于分析含义不变，但输入表结构不同的项目。

需要先写一张字段映射表：

| 语义 | 新数据字段 | 单位 | 是否必须 |
| --- | --- | --- | --- |
| 比较组 | 例如 `contrast_name` | 无 | 是 |
| 指标 | 例如 `feature_name` | 无 | 是 |
| 每组独立复本数 | 例如 `n_replicates` | 个 | 是 |
| 组间差异 | 例如 `estimate` | 按指标定义 | 是 |
| CI 下限/上限 | 例如 `ci_low`/`ci_high` | 与差异相同 | 是 |

然后按以下顺序改造：

1. 先在 `audit_config.json` 中完成路径和字段映射。
2. 如果只是列名变化，保持原工具不变。
3. 如果需要单位换算、长表转宽表或多文件合并，增加一个本地预处理脚本，并把输出固定成现有工具合同。
4. 只有当工具无法表达新数据语义时，才修改 `index.mjs`。
5. 在 `tests/run_local_cases.mjs` 增加一个新字段映射 fixture 和一个坏输入 fixture。

### C：科研方向工具包

适用于蛋白质、膜体系、聚合物、配体结合等方向，需要新的指标或判据，但仍以汇总证据为输入。

一个方向工具包必须同时提供：

- `data/audit_config.json`：输入文件、字段、单位、条件和门槛；
- `index.mjs` 或独立工具模块：确定性计算和错误码；
- `.agh/skills/<skill-name>/SKILL.md`：调用顺序、反馈处理和结论限制；
- `data/run_manifest.json`：数据范围和排除项；
- `data/provenance.json`：来源、脚本、版本和处理方法；
- `tests/`：正常、边界、缺失文件、坏格式和非法数值；
- `execution_evidence/`：本地测试和 AGH Host 运行摘要。

建议直接套用下面的方向模板：

| 科研方向 | 第一版建议工具 | 必须声明的边界 |
| --- | --- | --- |
| 蛋白质构象 | RMSD/RMSF、Rg、二级结构汇总、接触占有率 | 不能把短轨迹稳定性当成折叠热力学结论 |
| 膜体系 | 膜厚、面积、脂质接触、有序参数 | 不能把单盒结果当成尺寸收敛结论 |
| 聚合物/凝聚 | 接触、桥连、簇大小、最大连通分量、Rg | 不能仅凭网络指标证明宏观相分离 |
| 配体结合 | 接触占有率、氢键、复本差异、PMF 摘要 | 不能把局部井深直接称为标准态结合自由能 |

### D：新计算方法

适用于需要重新定义计算本身的任务，例如新的 PMF 坐标、QM/SAPT、反应势垒或自由能分解。

这类项目不能只修改配置。必须先写方法说明，固定：

- 物理量定义和单位；
- 采样对象和独立统计单位；
- 质量门槛；
- 不确定性方法；
- 可支持和禁止的主张；
- 一个正例、一个边界例和一个失败例。

方法模块完成后，再接入 AGH 工具和 Skill。模型只负责按流程调用，数值必须来自确定性工具。

## 用户提交什么，项目返回什么

用户提交 `customization/project_profile.template.json` 的填写版，以及约定格式的汇总数据。项目返回：

1. 可安装的 AGH 插件或配置包；
2. 对应 Skill；
3. 本地验证命令；
4. 正常、边界和失败测试记录；
5. 证据清单、工具结果、来源和结论边界。

用户不需要自行决定“应该改配置还是重写工具”。提交材料中只需说明研究问题、输入文件、指标定义和期望比较，项目按上面的路径分流。

## 当前版本的固定验收门槛

- 清单能明确报告完整、缺失和结构错误；
- 每个数值字段都能通过有限值和区间顺序检查；
- 独立复本数和统计单位写入结果；
- 置信区间跨零时输出“方向未分辨”；
- PMF 明确是否做标准态修正；
- SAPT/代理模型明确验证范围，不包装成普适设计规则；
- 所有结果都能回到证据文件和工具调用记录；
- 不把原始轨迹、未授权数据或凭证放入提交包。

## 当前交付范围

本轮优先保证 A/B/C 三条定制路径可复用，并保留 D 的接口。原始 MD 轨迹通用解析、自动指标计算、任务队列和复杂可视化暂缓；它们属于后续产品化工作，不作为本次黑客松交付前置条件。

## 随包演示版说明

本发行版输入为团队构造的合成测试数据，条件为 DEMO_A/B/C，MD 比较为 DEMO_A-minus-DEMO_B。模板是需求说明，不会被 Host 自动解释为新分析算法。A/B 路径已有配置映射测试；C/D 路径说明进一步开发与方法验证的步骤，不能据此声称已支持所有科研方向或任意计算方法。表中工期仅为原型改造估算，不构成完成承诺。
